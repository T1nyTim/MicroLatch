# MicroLatch

A Seal expansion for Balatro.

## Current content as of 0.1

- 20 new Seals
- 1 new Spectral card: Signet

## Dependencies

- Lovely >= 0.9
- Steamodded >= 26.829.0

## Installation

1. Download the latest MicroLatch release.
2. Extract it into your Balatro `Mods` folder.
3. Launch Balatro.
